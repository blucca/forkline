# Forkline visual direction

A pocket robotics studio where two futures occupy one tabletop. The robot arena is the product and the first-screen hero. The original wears a dashed cobalt route; the remix wears a solid coral route. Changed instructions look like punched toy-program tiles. The first divergent beat is the single emphatic reveal.

- Palette: cool violet paper #eeeafa, ink plum #352b50, parent cobalt #344cdb, remix coral #e47768, gate gold #ffd879, chalk #fbfcff.
- Type: Chakra Petch 600/700 for the compact wordmark, headline and mechanical counters; Atkinson Hyperlegible for instructions and controls. Sentence-case labels describe exact actions.
- Layout: one wide tabletop at left, a slim remix workbench at right. Beneath the arena, parent/remix instruction strips share the same numbered time axis. The ancestry becomes a quiet horizontal route, not a dashboard grid. On mobile the workbench follows the arena; OBS mode gives the stage nearly the full viewport.

```
Forkline                       Channel / Listen
One change. Two futures.
[      robot arena + two traces       ] [choose instruction]
[      clock / first divergence       ] [F / L / R / W]
[ Original #0: numbered route tiles   ] [Make remix]
[ Remix #1: changed tile + author     ] [exact chat command]
[      replay / ancestry / share      ]
```

Brief review: a dark dashboard with acid green would hide the toy and resemble the existing chat tools. A card grid would make programs feel like administrative data. This plan uses a cool daytime tabletop, physical instruction tiles, dashed-versus-solid paths, and synchronized moving parcels. Color reinforces shape and text; failures name the blocked beat and place. The only unsolicited animation is the initial labelled example replay, demonstrating the core behavior. Keyboard actions, reduced-motion replay and narrow screens remain functional.
